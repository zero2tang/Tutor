## 范围与数据口径

## 体验入口

启动应用后选择“初中数学 · 一元一次方程”，点击“一元一次方程”开始。
题库入口也可以选择其他已核验样题。

1. 原题为 `-2(x-3)=8`，先输入错误步骤 `-2x-6=8`。
2. 系统保留最后正确等式，并提出负数乘法诊断补问。
3. 回答 `6` 或 `-6`，系统记录具体观察，不直接把学生标为“不会分配律”。
4. 使用“给一点提示”：关注位置 → 相关规则 → 一个局部步骤。
5. 可以主动查看完整讲解；这会标记为辅助学习。
6. 完成本题后点击“独立新题验证”。
7. 新题 `-3(x-2)=12` 可按 `x-2=-4 → x=-2` 求解，不要求复现唯一参考步骤。
8. 未用提示、未见过题目且正确完成时，记一次独立近迁移验证；一题通过不表示长期掌握。

## 核心调用链

```text
现有 /sessions/{id}/messages 或 /practice
    → LearningService 的课程分发 → EquationTutoringService

/sessions/{id}/tutoring
    → execute_operation（原有 SSE 与事件落库）
    → LearningService.claim（原有会话占用）
    → 冻结题目校验 + 方程步骤核验
    → 教学状态转换 / 错因补问
    → AgentRunner 选择当前允许的教学卡片
    → 发布校验
    → 同一事务保存状态、原始输入、教学消息、证据和幂等回执
    → 发布正式消息与 tutoring 状态
```

## P0：正确性边界

- 修复全局字面答案比较中删除花括号和反斜线导致分数碰撞的问题。
- 数学解析不使用 `eval`。支持 `x`、常数、括号、加减乘除和部分 LaTeX 分数。
- 用精确有理数表示一次式 \(ax+b\)，在实数域比较具有唯一解的方程解集。
- 接受不同的合法解法，不比较学生步骤是否逐字匹配参考解。
- 拒绝非一次式、变量分母、零分母、多重等号、函数调用、缺少运算符或超出运算预算的表达式。
- 无法解析返回 `ungraded`，不把不受支持的输入当成学生概念错误。
- 题目内容、参考步骤和参考答案均在发布前检查，并保存版本与指纹。
- Agent 只能选择当前允许的教学卡片，模型自由文本不直接进入学生界面。
- 卡片内展示的等式必须与核验清单一致；公式及诊断算式再次接受程序检查。
- 新课程使用核验后发布的短片段；原有课程的普通文本流不在此次数学发布保证范围内。

这些规则只覆盖明确受限语法，不覆盖任意自然语言证明、手写识别、
几何、含参数讨论、含未知数分母或任意上传题。独立解法中的文字理由也尚未逐句评估。

## P1：教学与证据

诊断阶段区分 `tentative`、`observed_correct`、`observed_error` 和 `unresolved`。
当前有针对负号去括号错误的诊断补问；其他改变解集的错误提供检查方向，
不强行给出唯一错因。诊断规则覆盖范围不是整个初中数学。

提示从关注位置、规则提醒到局部示范逐级增加。完整讲解由学生主动选择。
错误后的纠正反馈、诊断补问和提示都会使本题退出“无帮助独立验证”口径。

证据分别记录原始步骤、局部诊断观察、提示等级与次数、辅助学习、
仅给最终答案与有中间等式的完成、初次练习与新题验证。
学习流程完成不等于已经验证长期掌握。

同一道题或同一学生已见题目不会重新计作新题验证。
题目池用完后明确停止，不循环旧题增加独立证据。

“这道题需要复核”会暂停本题，并将该题排除出有效汇总，原始记录保留。
当前没有真人教师处理队列，不会假称申诉已经被人工处理。

## 持久化与恢复

- `LearningSession.pending_context.equation_tutoring` 保存冻结契约和教学控制状态。
- `TutoringAction` 以会话和请求键唯一约束，保存请求指纹及完整公开回执。
- `TutoringEvidence` 保存原始输入、判定、提示、题目指纹、公开卡片指纹及模型调用关联。
- 状态、用户消息、教师消息、证据和回执在一个事务内提交。
- 教学消息保存事务版本与轮内序号，数据库时间精度只有秒时，刷新后仍先显示学生作答再显示教师反馈。
- 模型请求不持有写事务；提交前重查会话执行归属与状态版本。
- 重试不重复增加证据或调用模型；旧版本页面的写入被拒绝。
- 浏览器刷新直接恢复数据库状态。普通接口 `skip` 不能清除分步教学状态绕过证据约束。
- 模型不可用时降级为同一集合中的核验卡片，回执标记 `verified_fallback`。
