# 力学版本实现与验收

> 历史 V1 快照：以下内容保留原力学单课程交付时的实现与验收记录，不覆盖后续结果。2026-10-19 已扩展为力学与数学双课程；最新数据、14/14 数据库验收、4/4 数学四 Agent 流程及 19/20 力学回归见 [05 物理与数学数据库扩展](05_physics_math_database.md)。本轮力学 T14 置信度为 0.6，和本文较早记录的 0.76 属于不同次模型运行，不能混合统计。

本页说明当前真正运行的功能。四门课程的总体方案保留在其他设计文档中，当前网页仅开放力学课程。启动、配置和重建入口见 [项目说明](../../README.md)。

## 实现边界

| 模块 | 已实现行为 | 核心源码 |
|---|---|---|
| 主 Agent | 单点/多点目标规划，选择讲解、练习、题解、复习或澄清；评估后再次决定下一步 | `backend/app/application/learning/service.py` |
| 知识点 Agent | 基础、进阶、综合教学；公式与例子；结合历史消息、学习状态与记忆连续追问 | `backend/app/agent/skills/knowledge/` |
| 习题 Agent | 原题选择、记忆/理解/应用变式、独立解答一致性校验、分步题解 | `backend/app/domains/practice/service.py` |
| 评估 Agent | 作答前预测、真实作答后的诊断与汇总、比较预测偏差后提出一次有界修正 | `backend/app/domains/assessment/service.py` |
| 运行时 | 真实工具调用、结构化校验、有限重试、角色与技能记录、Tokens/耗时、SSE 事件持久化 | `backend/app/agent/runtime/runner.py` |
| 网页 | 学习空间、知识地图、查题、练习卡片、评估回执、档案、会话历史 | `frontend/src/features/` |

四个角色共享一个 Python 运行时，但有独立角色、技能文件、工具白名单和运行记录。不是四个常驻服务；同一模型分别承担角色。知识点学习的 `advanced` 技能对应综合教学，学生状态的 `advanced` 对应“进阶”层级，这两组名称不能混为同一指标。

当前的角色工具权限由服务端执行：

| 角色 | 可调用的只读工具 |
|---|---|
| 主 Agent | 知识结构、RAG、学生状态 |
| 知识点 Agent | 知识详情、知识结构、习题检索、RAG、Graph RAG、学习记忆 |
| 习题 Agent | 习题检索、知识详情、知识结构、RAG |
| 评估 Agent | 知识详情、学生状态、Graph RAG |

所有写入由业务服务完成。模型不能自行写掌握度、执行 SQL/Cypher、访问文件或运行命令。公开题目接口与 ES 公开题目索引不包含标准答案；后端冻结题目契约，评估和题解按会话状态读取答案。

## 数据、RAG 与图检索

MySQL 独立库 `stem_tutor` 保存课程内容、不可变作答、学生状态、记忆、会话与运行事件。ES 使用两个专用索引，Neo4j 使用 `StemTutorConcept/StemTutorQuestion` 节点及专用关系。没有导入原数据集的历史学生交互。

| 内容 | 实际数量或方式 |
|---|---|
| 原始知识点 | 198 |
| 原始题目 | 177，其中 174 道可直接练习，3 道缺图题被阻止进入独立评估 |
| 检索材料 | 198 份概念上下文 + 21 份补充教学卡片，共 219 份 |
| 图边 | 281 条知识点同题关联，保留来源，未推断为先修关系 |
| embedding | DashScope `text-embedding-v4`，1024 维；仅公开教学内容进入向量索引 |
| ES | 实际版本 9.3.2，内置 CJK 分析器、BM25、cosine kNN |

普通 RAG 并行执行关键词召回与向量召回，在应用层按名次融合：

\[
s(d)=\sum_{c\in\{\text{keyword},\text{vector}\}}\frac{1}{60+\operatorname{rank}_c(d)}.
\]

这是 RRF 排序分数，不是相关性概率或答案置信度；不依赖 ES 的付费原生 RRF 功能。Graph RAG 从种子知识点在 Neo4j 扩展 1–2 跳，取得有来源的关联节点和边，再按扩展概念过滤 ES 材料检索。答案最终引用检索得到的文本，而不把“图中相连”当作先修关系或学生已经掌握的证据。

检索均检查课程与公开可见范围，图规模和返回条数有界。依赖出错时标记 `degraded`；题目可以退到数据库精确搜索，不冒充向量结果。题库搜索支持原始题号、关键词、语义混合、知识点及题型筛选。

## 学生状态与证据规则

参考 LEARNERCOMPASS 的 Assessment、Summary、Predict、Tracing；本版本是工程化借鉴，没有复现论文训练、AB-MCTS 搜索或论文效果指标。

- 作答前预测与题目契约一同保存；不读取尚未发生的本题回答。
- 选择题、多选题和可精确匹配的填空优先使用确定性判分；模型解释不能覆盖客观判分。开放文本的低置信判断保持未判定。
- 对知识点分别保存基础、进阶、熟练估计；未测为 `null`。首次证据用 0、0.25、0.5 的保守状态初始化，不能凭一道定义题确认全部层级。
- 后续修正幅度由服务限制：正确为 \([0,0.2]\)，部分正确为 \([-0.05,0.05]\)，错误为 \([-0.2,0]\)，并限制结果在 \([0,1]\)。仅一题或两题独立证据时分别封顶 0.5、0.8。
- 原题认知层级未知时，评估器依据题目实际考查内容判断；用户选择“理解”不会自动使定义题成为进阶证据。
- 看过题解、待答期间获取知识讲解、低置信诊断、未判定结果不提升独立掌握估计；同一题重复练习不累计独立证据。同一提交标识不能对应不同答案。
- “力学”课程总标签不由单题更新。作答与状态变更在同一事务提交，重复请求返回已有记录。

这些数值是保守工程策略，尚未通过学生群体数据标定。网页百分比表示诊断估计，不代表已校准的答对概率。会话保存原题、待答阶段和历史消息；服务重启保留事实，未完成的模型运行标记中断，不从模型记忆猜测恢复。

## 验收证据

最终增强验收为 **19/20（95%）**，达到至少 80% 的要求。唯一未通过的 T14 判分正确，但诊断置信度为 0.76，服务遵守 0.8 门槛，没有更新掌握估计，未满足该任务必须更新的断言。T16 幂等用例已独立执行并通过；T19 同时验证题解和待答期间知识讲解均不增加独立掌握证据。后续仍需校准诊断保守性，不能强行提高模型置信度来消除失败。旧版 18/20 原始记录保留在 `data/reports/history/mechanics_v1_final.json`，不同版本结果没有混合统计。

## 当前限制

1. 仅力学课程接入应用；其余三门数据等待后续相同标准的导入和验收。
2. 原始数据缺少系统教材和多数题目解析，补充卡片覆盖有限。超出检索证据的解释需要继续人工抽检。
3. 生成题使用同模型的独立上下文解答做一致性检查，没有外部教师逐题审核；不能保证所有生成内容正确。
4. 本机个人版本没有账号、联网部署、任务队列或并发压测；长模型调用通过事件展示阶段，未提供逐字模型输出。
5. 暂不实现视频动画生成和视频检索，也未实现规划中的偏好编辑、完整跨主题工作区、论文训练或群体学习增益评估。
6. 20 项固定任务检验功能路径，不足以度量整个课程的教学质量、泛化能力、检索召回率或模型准确率。
