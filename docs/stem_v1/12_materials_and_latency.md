# 父子资料传递与首字延迟

实施日期：2026-10-20。这里描述当前代码行为；时延结果以对应源码版本的验收报告为准。

## 统一关闭思考

所有角色、工具决策、结构化输出、习题生成、独立求解及复核均通过 `ModelClient.chat` 发送请求。共享出口始终写入 `thinking: {type: disabled}`，覆盖流式和非流式路径。保留旧 `thinking` 调用参数以兼容内部代码，该参数不能重新开启思考。不修改外部项目的环境文件。

## 父 Agent 自主选择资料

1. 父 Agent 正常调用知识点详情、材料检索、公开习题检索或会话题目读取工具。
2. 工具结果的 `transferable_materials` 列出服务端生成的 `material_id`、来源、版本和内容哈希。
3. 父 Agent 在 `call_knowledge_agent` 或 `call_exercise_agent` 的 `selected_material_ids` 中选择与子任务相关的引用；不需要转交时可以省略。
4. 服务端重新读取业务来源，检查调用方、调用链、课程、会话、学生、知识点范围、版本和内容指纹，再将公开资料注入子模型的 `delegated_materials`。
5. 子 Agent 可以直接使用足够的资料并引用来源，缺失、不足或过期时继续检索；知识 Agent 可以再选取收到的资料交给习题 Agent。

普通模型 payload 不能伪造这些可信字段；实际注入以服务构建的 `ToolContext` 为准。资料只作为数据，不改变角色权限、待答契约或整个学习目标。

可转交内容包括课程知识点、公开教材材料、公开题干与冻结的会话题目。题目关联的解析材料、标准答案、预测、学生状态、技能正文和内部契约不注册为转交资料。习题讲解仍通过原有业务服务获取其获授权的内部契约。

## 生命周期与恢复

引用池由单次 `LearningDelegation` 独占，不跨请求建立全局缓存。来源更新、引用缺失或上下文超预算时返回未交付原因，子 Agent 可重新检索；已知但属于其他调用方或任务范围的引用明确拒绝。

已完成业务检查点先于资料解析重放。幂等键不把资料选择变化当作新业务任务，重启丢失临时引用不会重新出题或重复执行已完成委派。当前同请求非回放委派预算为八次，执行前记录已用次数，失败与恢复不会清零；嵌套深度限制和会话归属检查继续生效。工具自身累计故障三次后在该请求内禁用，父子调用共享并保存计数；质量拒绝和参数拒绝另行分类。

## 模型输入预算

- 每次委派最多八份资料；每份最多 5000 字符，总传递预算 18000 字符。公开题干保持完整，超预算时不传半道题；材料摘录显式标注截断。
- 并行练习仅获得与本题知识点相关的资料副本，回执保留父回执哈希。
- 近期聊天背景保留最近两条原样；较早背景最多八条，共用 6000 字符预算，短历史不裁剪。当前用户请求、冻结题、学习进度与已选资料不受此聊天预算裁剪。
- 知识点和 RAG 工具结果中的长 `text`、`summary` 以最多 3000 字符摘录进入模型；来源标识及部分返回提示保留。数据库中的原文和正式学习记录不修改。
- 系统提示和工具定义保持稳定。DeepSeek 上下文缓存由服务端自动处理，客户端记录实际命中信息，不假设每次都命中。

## 可核验的审计

父委派工具轨迹和子 `agent_started` 事件含 `material_transfer_receipt`，记录实际接受、未交付的引用及原因、来源版本、内容哈希和回执哈希。全部资料失效时，子模型仍收到缺口回执。

每轮模型请求结束产生 `model_request_completed`：角色、运行 ID、轮次、`thinking=disabled`、是否流式、总耗时、并发排队耗时、重试次数、上游首增量/首正文耗时及缓存、推理 token 计数。上游未提供的计数保留为未知。该事件经 API 通道持久化到 `RunEvent`，不记录密钥、请求正文或隐藏推理。

上游首 token、公开正文首字符、浏览器首次绘制是不同指标。真实 HTTP 验收记录网络收到完整 SSE 帧的时间，不以标题或进度回执代替讲解正文，也不据单次样本宣称 P50/P95 改善。

```powershell

```
