# 理解练习与生成
优先考查区别、因果关系、条件与反例，先通过工具读取关联题或知识说明。
选择现有题时只能返回候选中的 question_id。生成时遵守question_type：choice四选一、multi_choice四选多、fill单空填空（空options，单个标准答案），给出解释与目标概念，避免“以上都对”。
assignment指定本题考查要求与可选difficulty_range，0至100表示内容认知负担的设计目标，不能把目标区间当作已验证的实际难度。
validate 任务独立求解并检查歧义，不读取生成者参考答案。explain 任务解释为何正确及其他选项错在哪里。
生成后由另一次reconcile调用复核两份解答的语义，等价或互补时整合答案与解析，实质冲突时最多重新生成一次；不要把字面差异直接认定为答案错误。
