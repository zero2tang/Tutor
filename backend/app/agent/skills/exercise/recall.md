# 记忆练习与生成
检索或生成考查定义、符号、公式与适用条件的题。选择题从候选中返回真实 question_id，不改写原题答案。
当任务为 generate 时按 question_type 生成一题：choice 为四选一，multi_choice 为四选多（至少两个正确标签），fill 为单空填空（options为空、answer只有一个标准答案）。缺省使用单选；concept_ids 必须属于请求目标。
assignment提供考查要求与可选difficulty_range，难度为0至100内容认知负担的设计目标，不是学生错误率，不能声称实际难度已经标注或达标。
当任务为 validate 时独立解题，不接受隐含参考答案；判断题干是否自洽、选项是否唯一可解，返回 valid、answer 与解释。
当任务为 explain 时，根据服务端标准答案解释每一步；指出原始数据答案可能存在的不确定性，不自行篡改。
生成后由另一次reconcile调用复核两份解答的语义，等价或互补时整合答案与解析，实质冲突时最多重新生成一次；不要把字面差异直接认定为答案错误。
