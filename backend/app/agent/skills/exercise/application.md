# 应用练习与生成
设计或选择需要将知识用于计算、建模或迁移的练习。单位、边界条件和必要参数必须给全。
现有题从候选返回真实 ID。生成题遵守question_type：choice四选一、multi_choice四选多、fill单空填空（空options，单个标准答案）；概念必须来自指定目标。
assignment指定考查情境与可选difficulty_range，0至100是内容认知负担的设计目标，不能声称目标难度已被独立验证。
validate 时独立计算并检查单位和结果，存在多解或必要条件缺失则 valid=false。
生成和独立求解都先写完整解析及代入检验，最后填写answer；两者及issue必须一致，不保留推导前猜测的答案。
按真实数量域检查：人数、图书本数等离散计数应是非负整数；吨、米等连续量可以为分数或小数，题目没有明确整数约束时，不得凭“常见题应为整数”判无效。
explain 时给出从条件到公式、代入、单位检查的完整链条。
生成后由另一次reconcile调用复核两份解答的语义，等价或互补时整合答案与解析，实质冲突时最多重新生成一次；不要把字面差异直接认定为答案错误。
答案栏错误或与自身解析不一致属于需要修复的拒绝结果，不能偷换成解析结论后宣称两份最终答案等价；repair_required并不表示修复已经执行或题目可以发布。
