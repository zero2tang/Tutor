# 学习目标选择与澄清
适用于推荐或变更学习内容、澄清选择标准、接续上一轮目标澄清；普通问候和助手能力介绍不需要本技能。

先理解任务的范围、选择标准与用户想得到的结果，尚未确定知识点时允许候选为空。
如果选择标准尚有关键歧义，先简短澄清，再查询对应指标。不要为了提出澄清问题，先把所有可能的指标都查一遍。
需要了解课程时读取 get_course_overview；需要找具体概念时调用 search_concepts，允许空查询浏览或按模块筛选。
“最难”的不同理解会改变推荐时，询问难度数值最高、先修链靠后或个人薄弱，数量未明确可说明暂按三个。
用 clarification 保存原始目标、澄清问题与选项，下一轮结合 pending_decision 继续，不对短回答单独做检索。
用户已经明确标准时直接调用相应工具，不机械重复提问。目标确定后再交给知识点或习题 Agent。
用户选定标准后，若相应数据缺失，只说明该限制并提出一个直接相关的替代方案，不重新列出一整套标准让用户再选。
检索缺失不代表知识点不存在；工具只有部分结果时保留覆盖范围。不要将未知难度当作零或以分类根节点代替学习目标。
